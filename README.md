# Payslip Portal (.NET)

سامانه‌ی ثبت و نمایش فیش پرداخت کارکنان، بازنویسی‌شده با ASP.NET Core.

## مسئله

شرکت‌های کوچک فیش پرداخت ماهانه‌ی کارکنان را معمولاً با اکسل و ایمیل رد و بدل می‌کنند:
کسی نمی‌داند کدام نسخه نهایی است، اصلاح یک عدد یعنی ارسال دوباره‌ی فایل به همه،
و هیچ ردی از این‌که چه کسی چه چیزی را کی تغییر داده باقی نمی‌ماند.

این سامانه یک جای واحد برای این کار است: مدیر فایل پرداخت را بارگذاری می‌کند،
سیستم آن را اعتبارسنجی و به‌صورت تراکنشی ثبت می‌کند، و هر کارمند فقط فیش خودش را می‌بیند.

## چی هست

- دو نقش مستقل: مدیر و کارمند (و نقش ناظر فقط‌خواندنی)
- بارگذاری گروهی کارکنان و پرداخت‌ها از Excel با مرحله‌ی پیش‌نمایش و سپس ثبت
- اجزای فیش قابل پیکربندی (مثلاً ثابت، عملکردی، بازگشت مالیات، سایر)
- ثبت نرخ ارز به ازای تاریخ و تبدیل جمع فیش به ارز دوم با snapshot نرخ
- تاریخ شمسی در دوره‌ها و نرخ‌ها
- لاگ اقدامات حساس
- بدون حذف فیزیکی رکوردهای اصلی

## چی نیست

- سیستم حقوق و دستمزد کامل نیست (بیمه، مالیات، مرخصی محاسبه نمی‌کند)
- اتصال به بانک یا پرداخت خودکار ندارد
- چندمستأجری (multi-tenant) نیست
