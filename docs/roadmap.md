# نقشه‌ی نسخه‌ها

هر نسخه یک tag روی GitHub است. هر نسخه فقط وقتی بسته می‌شود که ستون «تمام یعنی» برقرار باشد.

| نسخه | چی ساخته می‌شود | تمام یعنی |
|---|---|---|
| v0.1 | ریپو، README، ساختار پوشه‌ها، CI خالی | badge سبز روی README |
| v0.2 | دامنه: `Money`، `JalaliDate`، `PayrollPeriod`، `Statement` با اجزای پیکربندی‌پذیر و محاسبه‌ی ارز دوم (console) | ۱۰+ تست سبز؛ ADR-001 پول، ADR-002 تاریخ |
| v0.3 | `IEmployeeRepository`، `IStatementRepository` در حافظه + `StatementService` | سرویس بدون دیتابیس تست می‌شود |
| v0.4 | EF Core + MySQL + Docker Compose | `docker compose up`؛ ADR-003 schema |
| v0.5 | ورود، قفل حساب، تغییر رمز اجباری، سه نقش | موارد «حساب و امنیت» چک‌لیست پذیرش سبز |
| v0.6 | کارکنان + نرخ ارز (CRUD + بارگذاری Excel با پیش‌نمایش/ثبت) | موارد «کارکنان» و «نرخ» سبز |
| v0.7 | بارگذاری پرداخت + فیش + پرتال کارمند + لاگ اقدامات | موارد «پرداخت» و «پرتال کارمند» سبز |
| v0.8 | خروجی PDF فیش، گزارش ناظر، health، لاگ ساخت‌یافته | کل چک‌لیست پذیرش سبز |

## قانون‌های کار

- هر روز حداقل یک commit.
- تست قبل از کد.
- هر لایه فقط وقتی اضافه می‌شود که نیازش حس شده باشد، و همان‌جا یک ADR نوشته می‌شود.
- هیچ داده‌ی واقعی، فایل `.env`، یا سند داخلی شرکت در این ریپو قرار نمی‌گیرد.
